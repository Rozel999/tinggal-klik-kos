# Tinggal Klik Kos

Aplikasi Flutter yang memakai Supabase untuk pencarian dan pengelolaan kos di Kota Padang, Sumatera Barat. Tidak tersedia akun atau data demo.

## Peran aplikasi

- **Owner aplikasi (`app_owner`)**: superadmin; dapat masuk ke pusat moderasi dan mengelola admin. Role ini tidak tersedia di formulir daftar.
- **Admin (`admin`)**: moderasi listing, pengguna, dan aktivitas platform.
- **Pemilik kos (`kos_owner`)**: mendaftarkan kos dan mengelola listing/kamar miliknya.
- **Pengguna (`customer`)**: mencari kos, favorit, booking/survei, chat, dan tagihan.

Pendaftaran mandiri hanya menyediakan Pengguna dan Pemilik kos. Admin dan Owner aplikasi harus ditetapkan melalui proses backend tepercaya.
